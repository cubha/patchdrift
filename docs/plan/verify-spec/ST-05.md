### VERIFY-SPEC — SubTask ST-05

- 기준선 요구사항: "통계 엔진 — Wilson CI, Newcombe 두 비율 차이 CI, BH-FDR, beta-binomial 축소, 최소 n 게이트 판정" (PLAN ③ ST-05 행, F2 소비). PLAN ① F2 원문: "챔피언 픽률·밴률·승률(포지션별), 아이템 채택률(완성템 6슬롯). Wilson/Newcombe CI, 승률 최소 n 게이트, BH-FDR". PLAN ② 제약: "승률 델타는 n≥200 게이트 + Newcombe CI 비중첩 + BH-FDR q<0.10 통과 시만 '관측된 변화', 미달=`insufficient-sample`". RESEARCH §3-2: 2,000매치 표본에서 챔피언당 100~120게임 → 승률 95% CI 반폭 ±9~10%p이므로 "승률 델타만으로 미공지 판정 불가" → 권고 스택 = Wilson(단일 비율) + Newcombe-Wilson(차이) + beta-binomial 경험적 베이즈 축소(저픽률 왜곡 완화) + 최소 n 게이트 + BH-FDR(170챔피언×다지표 동시검정 거짓양성 통제).

- 관찰 가능한 계약:
  - `wilsonInterval(successes, n, z=Z_95): Interval` — `n=0` → `[0,0]`. 경계는 `[0,1]`로 클램프(부동소수 오차로 음수/1 초과가 나올 수 있음). 기지값: `(0,10)`→`≈[0,0.278]`, `(5,10)`→`≈[0.237,0.763]`, `(100,10240)`→폭 `≈0.002`, `(50,100)`→반폭 `≈0.098`, `(500,10000)`→반폭 `≈0.004`.
  - `newcombeDiffInterval(s1,n1,s2,n2,z=Z_95): Interval` — Newcombe(1998) 방법 10(두 그룹 각각 Wilson CI를 구한 뒤 hybrid score로 결합). **인자 순서는 (이전 s1,n1) → (이후 s2,n2)이고 반환 구간은 `p2-p1`(이후-이전) 방향** — aggregate/verdict 소비처가 "패치 후 얼마나 변했나"를 바로 읽도록 통일. 기지값 `(56,70,48,80)`→`≈[-0.34,-0.06]`(허용 0.02). 동일 비율이면 0을 포함.
  - `twoProportionPValue(s1,n1,s2,n2): number` — 풀드 z검정 양측 p. 동일 비율 → `≈1`, 극단 차이 → `<1e-6`. 정규 CDF는 자체 구현한 erf 근사(`|x|<=4` 매클로린 급수 직접합산, `|x|>4`는 `sign(x)`로 클램프 — 근거는 구현 결정 참고) 기반.
  - `benjaminiHochberg(pValues, alpha=FDR_ALPHA): {q, rejected}` — `q`는 원래 순서 그대로, 단조 비감소 보정 + `[0,1]` 클램프. `rejected[i] = q[i] <= alpha`. 빈 배열 → `{q:[], rejected:[]}`. 기지값 `p=[0.01,0.04,0.03,0.005]`, `alpha=0.05` → `q=[0.02,0.04,0.04,0.02]`(원래 순서), 전부 기각.
  - `betaBinomialShrink(successes, n, priorMean, priorStrength): number` — `(successes + priorMean*priorStrength) / (n + priorStrength)`. `n=0` → `priorMean`, `n`이 매우 크면 → `successes/n`(표본비율)로 수렴.
  - `passesSampleGate(nBefore, nAfter, minN=WIN_RATE_MIN_N): boolean` — 둘 다 `minN` 이상이어야 `true`. `199 < 200 <= 200` 경계 확인.
  - `meanDiffInterval(mean1,sd1,n1,mean2,sd2,n2,z=Z_95): Interval` — Welch 근사(등분산 가정 없이 `se=sqrt(sd1²/n1+sd2²/n2)`, `z`배 정규근사), 반환은 `mean2-mean1` 방향.
  - `summarize(values): {n, mean, sd}` — `sd`는 표본표준편차(ddof=1). `n=0`→`{0,0,0}`, `n=1`→`sd=0`.
  - export 상수: `WIN_RATE_MIN_N=200`, `FDR_ALPHA=0.10`, `Z_95=1.96` — 각각 `passesSampleGate`/`benjaminiHochberg`/`wilsonInterval`·`newcombeDiffInterval`·`meanDiffInterval`의 기본값으로 배선됨.
  - 모든 함수는 순수 함수(부수효과 없음), 외부 통계 라이브러리 의존 0(erf까지 자체 구현), `any` 미사용.

- 구현 결정:
  - **erf 근사를 매클로린 급수 직접 합산으로 구현**(Abramowitz-Stegun 7.1.26 등 표준 근사식은 최대오차 1.5e-7로 스펙 목표 "<1e-7"를 만족 못 함). node로 기지값(`erf(1)=0.8427007929497149` 등) 대조해 `|x|<=4` 구간은 오차 `~1e-10`~`1e-16` 확인. `|x|>4`는 급수 항이 지수적으로 커졌다 줄어드는 과정에서 상쇄오차로 무너짐을 실측(`erf(5)`가 series로 `1.00000007`, 오차 7e-8; `erf(6)`은 `0.998`로 완전히 붕괴)했으므로 `sign(x)*1`로 클램프 — 이때 최대오차는 `erfc(4)=1.5e-8`로 스펙 목표 이내. 이 근거는 코드 주석에도 남겼다.
  - `wilsonInterval` 결과를 `[0,1]`로 클램프했다 — `successes=0` 케이스에서 부동소수 연산 결과 `low`가 `-2e-17`로 나오는 것을 실측, 비율 CI가 정의역을 벗어나면 소비처(ChampionRateCi 등)가 음수 픽률을 렌더링하는 문제를 예방.
  - `newcombeDiffInterval`/`meanDiffInterval`의 인자 순서·반환 방향을 "이전→이후, 이후-이전"으로 고정했다 — PLAN이 명시하지 않았으나 `DeltaRecord.before/after/delta`(types.ts, ST-01) 필드 명명과 일치시키는 것이 ST-06/ST-08 소비 시 부호 혼동을 없앤다는 판단(자체 결정, 문서화로 명시).
  - `twoProportionPValue`에서 pooled 분산이 0인 경우(두 그룹 다 100% 또는 0%)는 비율이 같으면 `p=1`, 다르면 `p=0`으로 처리 — 이 케이스는 귀무가설(비율이 같다)이 관측과 모순되므로 정의상 유의성이 최댓값이라는 판단. 스펙에 명시되지 않은 엣지케이스라 테스트로 커버(`twoProportionPValue(100,100,0,100) < 1e-6`).
  - `benjaminiHochberg`의 `q`값을 `[0,1]`로 클램프했다 — 표준 BH raw q(`p*m/rank`)는 1을 초과할 수 있어(스펙에 명시 없으나 통계 관행) q-value 정의(추정 FDR)상 확률처럼 다뤄지려면 클램프가 맞다는 판단.
  - stub/fallback/하드코딩 없음. 스텁의 기존 타입 `ConfidenceInterval {low,high}`는 폐기하고 지시받은 대로 `types.ts`의 `Interval`(`=[lo,hi]`)로 전면 교체했다 — 소비처(`champions.ts`/`items.ts`/`lanes.ts`/`objectives.ts`)는 확인 결과 아직 `stats.ts`를 import하지 않는 스텁 상태라 하위호환 이슈 없음.
