## 1. 프로젝트 UX 컨텍스트
- 목적: 패치 전후 매치 통계 델타를 공식 패치노트 항목과 자동 대조하고, 짝 없는 델타(미공지 변화)를 근거와 함께 브리핑
- 타겟: LoL KR 코치·클랜장·분석 스트리머 — 패치 후 24~72h, 데스크톱 우선(1440), 모바일은 읽기 전용 축약
- 핵심 인터랙션: 패치 쌍 선택 → 미공지 목록 스캔 → 항목 상세에서 근거(CI·원천 매치·패치노트 원문) 확인 → 디스코드 전송
- 불변 원칙: 모든 판정문에 원천 링크 · 무근거 문장 회색 · 승률은 n 게이트 미달 시 "표본 부족" 라벨(델타 미제시)

## 4. 핵심 사용자 플로우 (해피 패스)
1. **패치 후 브리핑**: 홈 진입 → 필터 "26.16 → 26.17" → 미공지 5건 스캔 → 1건 클릭 → 상세에서 CI·원천 매치·패치노트 부재 확인 → 디스코드 전송
2. **노트 검증**: 홈 "공지 대조 미리보기 → 전체 보기" → 대조표 좌 내비에서 "나서스" 선택 → 우 테이블 하이라이트에서 관측 방향 확인(공지-일치) → 상태 필터 "공지-불일치"로 전환해 노트와 반대로 움직인 항목 확인
3. **방법 확인**: 헤더 "방법론" → 상태 정의·게이트 확인 → 디스코드 미리보기로 팀 공유 형태 확인
